🔐 Password Generator (Node.js)

A simple Node.js script that takes user input and generates a unique password instantly.

🚀 Features
Takes user name and favorite number as input
Generates a random and unique password
Lightweight and easy to use
Runs in terminal (CLI-based)
🛠️ Tech Stack
JavaScript (Node.js)
readline module
📦 Installation

Clone the repository:

git clone https://github.com/your-username/password-generator.git

Navigate to the project folder:

cd password-generator
▶️ Usage

Run the script using Node.js:

node password-generator.js
🔑 How it works
User enters name
User enters favorite number
Script combines inputs with random characters
A unique password is generated
💡 Example Output
Your name? Vansh
Your favorite number? 7
Generated Password: Vank3j9x7!
